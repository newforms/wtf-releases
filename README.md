# WTF releases

Download builds and the Sparkle update feed for [WTF](https://github.com/newforms/whiskey-tango-foxtrot), a macOS menu bar app that helps you spell words out loud.

- **Latest build:** see [Releases](https://github.com/newforms/wtf-releases/releases)
- **Update feed:** `appcast.xml` (the app checks this itself)

Requires macOS 15 or later.
